# 模块八：飞机称重与重心（Weight & Balance）— 验收说明

实机称重登记、空重与重心计算、包线折线插值判定、版本化称重规则、双人复核基线、构型调整链与版本对比。
判定全部在后端（`WbCalculator` 无状态 Decimal 计算 + `WbService` 事务纪律），前端只做原始单位/统一单位切换展示。

## 1. 计算口径（统一精度，无累积误差）

- 统一内部单位：**kg / mm**；1 lb = `0.45359237` kg，1 in = `25.4`（精确常数）。
- 固定精度 `HALF_UP`：重量 6 位小数 kg、臂长 3 位 mm、力矩 3 位 kg·mm、重心臂 3 位 mm。
- 每次都从**原始读数 + 原单位**重新换算，或直接读登记时冻结的快照；不做任何「单位来回折」的增量累计，
  因此重复试算/重复打开结果逐位相同。
- 重心臂 = 最终总力矩 / 扣补后最终重量；包线前/后边界 = 重量所在两节点之间的**线性插值**。

结论三态：

| 结论 | 条件 |
|---|---|
| `INSIDE` 包线内 | 重量在许用范围内且重心臂介于插值前/后边界之间（含边界） |
| `OUTSIDE` 包线外 | 重量越界（`OVER_WEIGHT`/`UNDER_WEIGHT`，差值 kg）或重心越界（`FORWARD` 偏前 / `AFT` 偏后，差值 mm） |
| `UNDETERMINED` 无法判定 | 任意读数缺失、支点不属于所引用规则、非法数值（非数字/负数/净重为负）、重量落在折线节点覆盖范围之外 |

后三类一律**不得**给出「包线内」，并在 `issues` 中逐条列出原因。

## 2. 版本化规则（不得改写历史）

- `wb_rule_version`：DRAFT 草稿（可改）→ EFFECTIVE 已发布 → SUPERSEDED 冻结；同机型 `R0/R1/…`。
- 新版可设生效日期：**未来才生效的新版不影响当天称重选版，也不提前冻结旧版**；按称重日期选
  「已发布且生效日 ≤ 称重日期」中最新的一版。
- 称重记录固化 `rule_revision_id/version_no`；构型链始终沿用基线规则版本。规则再修订，
  历史称重与历史构型版本仍按当时结果快照展示，**绝不重算覆盖**。
- 规则含：基准点（datum）、各起落架支点编号与臂长、许用总重区间、前后两条重量-重心臂折线
  （每边 ≥2 个严格递增的重量节点）。

## 3. 称重与基线

- 一次称重记录：飞机、日期、秤具编号、引用规则版本、燃油/滑油条件、支点毛读/皮重、
  临时扣补项（ADD 补入 / DEDUCT 扣除，含数量、原因），每行保留**原始读数字符串与原单位**
  及换算后的 kg/mm 快照。
- 结果：各支点净重、毛重/毛力矩、扣补后最终重量/力矩、重心臂、插值边界、判定与越界差值。
- **不同人复核**（称重人与复核人不能相同）→ CONFIRMED；仅 `INSIDE` 可设为当前称重基线（构型 v0）。
- 重新设基线会归档旧链（历史全部保留），新链从 v0 开始。

## 4. 构型调整链

- 安装/拆除调整项：动作、单位重量、臂长、数量、原因、关联工卡（支持 kg/mm 或 lb/in）。
- 只能从**当前版本**（`active_aircraft_id` 唯一占位 + 悲观锁）继续派生；旧版本不可分叉。
- 调整项行冗余 `aircraft_id`，服务端只允许本机派生，对比接口拒绝跨机版本。
- 每个版本固化当时重量/力矩/重心臂/判定/插值边界；越界时精确给出方向与差值。
- 曾经合格的历史版本永远按当时结果展示（v0/v1 包线内、v2 包线外、v3 回包线内均可并列保留）。

## 5. 现有台账兼容

没有称重基线的飞机（如 A330 的 B-6571/B-7411、未称重的 ARJ21）在模块中明确标 **「未建立基线」**，
当前重量/重心/判定均为空，**不猜默认重心**；飞机台账等其他模块不受影响。

## 6. 页面（顶部「⚖️ 称重与重心」）

① 机队基线档案 ② 称重规则版本（含折线/支点） ③ 称重记录 ④ 构型调整链（时间线+版本对比）
⑤ 审计事件；称重录入抽屉带「服务端试算」实时预览。顶栏可切换 **统一 kg/mm · 统一换算 lb/in ·
原始单位**，三套视图来自同一份后端结果。
